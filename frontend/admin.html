College Presentation Testbed: Trigger safe, locally confined scenarios below (or perform real failed logins in the User Portal) to demonstrate the 9-stage Digital Immune System workflow in real time.

1. Repeated Failed Logins

Simulates brute-force login attempts from a safe RFC 5737 test IP, triggering detection, risk scoring, incident creation, and temporary IP blocking.

2. Suspicious Request Burst

Simulates rapid API polling exceeding configured request-frequency thresholds from a test IP.

3. Restricted Endpoint Probe

Simulates repeated unauthorized probes against a protected administrative debug endpoint.

4. API Service Failure

Injects a local simulated API gateway failure, transitions health to Critical, and logs an availability incident.

5. Database Failure

Simulates a database connection pool outage while keeping local recovery diagnostics available.

6. Excessive Error Events

Simulates a burst of HTTP 500 error events that degrades service stability and triggers circuit-breaker recovery.

7. Trigger Self-Recovery

Runs the Self-Recovery Engine to restore failed simulated services, re-verify SQLite health, and resolve outage incidents.

8. Normal Baseline Traffic

Generates legitimate user traffic to verify zero false-alarm blocking or spurious incident escalation.
